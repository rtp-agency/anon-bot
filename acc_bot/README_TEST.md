# Локальный тест бота сверки

## Что в папке

- `bot.py` — основной код бота
- `requirements.txt` — Python-зависимости
- `.env.example` — пример переменных окружения
- `seed_test_db.py` — создаёт пустую тестовую БД с тремя «секретными ботами» (фейковыми, чтобы было что выбрать в UI)
- `anon-acc.service` — systemd-юнит для деплоя на сервер (на локал не нужно)

## Быстрый старт на Windows

В терминале (PowerShell или Git Bash), в папке `acc_bot/`:

```bash
# 1. Создать виртуальное окружение
python -m venv venv

# 2. Активировать (PowerShell)
.\venv\Scripts\Activate.ps1
# Или Git Bash:  source venv/Scripts/activate

# 3. Поставить зависимости
pip install -r requirements.txt

# 4. Скопировать .env
cp .env.example .env

# 5. Создать тестовую БД (заглушки для секретных ботов — UI будет работать,
#    но реальная рассылка по фейковым токенам вернёт 401 от Telegram)
python seed_test_db.py

# 6. Запустить
python bot.py
```

Открой в Telegram бота `@<имя_бота>`, нажми `/start`.
Так как ID `5252506422` зашит как первый Owner — ты сразу получишь полный доступ.

## Что можно потестить локально (без рассылки)

- Создание группы, привязка фейковых ботов
- Ввод курсов
- Ввод данных по группе (одной суммой или построчно)
- Формирование сверки — превью будет работать, расчёт правильный
- Управление ролями (добавить второй Owner / Admin)
- История

## Что НЕ потестить локально

**Отправку сверки/курсов в реальные чаты.** Локально привязанные «боты» имеют фейковые токены — Telegram-API вернёт 401 при попытке отправить. В превью увидишь "0 ок / N ошибок". Для полного теста нужен деплой на сервер где есть настоящие токены.

Если хочешь полный тест локально — скопируй продовую `data.db` со старого сервера в эту папку и переименуй в `data.db`. Но **осторожно** — если что-то насетапишь и потом я задеплою на сервер, локальные изменения там не появятся.

## Сброс локального состояния

```bash
rm data.db
python seed_test_db.py
```

## Когда готов к серверу

Скажи мне «деплой» — я положу `bot.py` в `/home/anon-bot-acc/`, поставлю systemd-юнит, запущу. Локальные acc_* таблицы создадутся в общей `data.db` на сервере при первом старте; данных там пока нет — начнёшь с нуля.
